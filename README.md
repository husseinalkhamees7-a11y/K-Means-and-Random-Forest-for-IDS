This code presents a hybrid intrusion detection system that integrates K-Means clustering with the Random Forest algorithm to improve multiclass network traffic classification. By combining unsupervised and supervised machine learning techniques, the model effectively captures latent traffic patterns and enhances detection performance. The study addresses class imbalance using the Synthetic Minority Over-Sampling Technique (SMOTE) and evaluates feature selection through both Principal Component Analysis (PCA) and Chi-squared (Chi²) methods across multiple feature subsets. The use of Silhouette Coefficient and Davies–Bouldin Index ensures the optimal number of clusters is selected. Performance is comprehensively assessed using accuracy, precision, recall, F1-score, Matthews Correlation Coefficient (MCC), Adjusted Rand Index (ARI), and execution time. Experimental results on the CICIDS2017 dataset demonstrate outstanding performance.

Reproducibility instructions:
This repository contains the implementation of the Hybrid Intrusion Detection System (K-Means + Random Forest)
evaluated on the CICIDS2017 dataset. The code was built and tested using Python version 3.12.0 (key libraries:
NumPy, Pandas, Scikit-learn, Matplotlib).
